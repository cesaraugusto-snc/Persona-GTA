# 🌆 GTA Dev City - Escolha de Personagem & IA

Um projeto web interativo desenvolvido durante as formações da **DevClub**, combinando a estética marcante inspirada em jogos de mundo aberto com recursos modernos de Inteligência Artificial via **Puter.js**.

🌐 **[Clique aqui para testar o projeto online](https://cesaraugusto-snc.github.io/Persona-GTA/)**

---

## 🚀 Tecnologias Utilizadas

- **HTML5** & **CSS3** (com responsividade adaptada para dispositivos móveis)
- **JavaScript (Vanilla)**
- **Puter.ai API** (integração para transformação de fotos em avatares estilo videogame)
- **Google Fonts** (Fontes *Bangers* e *Inter*)

## ✨ Funcionalidades

- **Seleção de Personagens Clássicos:** Alterna instantaneamente o nome, a cor de destaque e a imagem principal do personagem na tela.
- **Modo Selfie / IA:** Permite carregar uma foto própria (`input file`) e transformá-la instantaneamente em arte digital interativa no estilo do jogo.
- **Design Responsivo:** Layout estruturado para computadores (mantendo a experiência original do projeto) e adaptado com media queries fluídas para celulares.

## 📱 Prévia do Layout

O projeto foi pensado para manter a fidelidade visual nos monitores de PC e reorganizar os elementos perfeitamente em telas menores de smartphones.
